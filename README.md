# Otome Shimai — podcast website

Static website for the [Otome Shimai](https://otomeshimai.buzzsprout.com/) podcast:
about/intro, latest episodes (pulled live from the Buzzsprout RSS feed in the browser),
game walkthroughs, streaming links, and socials. No server and no build step — plain
HTML/CSS/JS, deployable to any static host.

## Preview locally

```bash
python -m http.server 8360
# then open http://localhost:8360/
```

(A server is needed — the episode feed and walkthroughs are fetched with `fetch()`,
which doesn't work from `file://`.)

## Deploy

Point any static host at this directory — Cloudflare Pages, GitHub Pages, Netlify, etc.
No build command; the publish directory is the repo root. The site works from a subpath
too (all URLs are relative).

## Editing the site — where everything lives

No build step and no admin panel: edit the file, refresh the browser. (Once deployed,
re-upload / git push to publish the change.)

| What you want to change | Where |
|---|---|
| Page title / tab title | `index.html` — the `<title>` tag and `<meta name="description">` near the top |
| Podcast name, subtitle, about text | `index.html` — the `<section class="intro">` block (plain HTML text) |
| Streaming links (Spotify, YouTube Music, …) | `index.html` — the "Listen Everywhere" section; each link is one `<a class="pill">` line. Copy a line to add a platform, delete a line to remove one |
| Social links (Instagram, Twitter, Bluesky, Ko-fi) | `index.html` — the `<footer>` block, same one-line-per-link pattern |
| Footer disclaimer text | `index.html` — the `<p class="disclaimer">` in the footer |
| Walkthroughs | `walkthroughs/*.md` + `walkthroughs/games.json` (see below) |
| Cover art / banner image | Replace `assets/cover.jpg` (square) / `assets/header.png` (wide, flat `#23b4ff` background so it blends). Then run `python make-icons.py` to refresh the favicon/app icons |
| Colors / fonts | `shared.css` — the `:root { --sky: … }` block at the top |
| App name when installed as PWA | `manifest.webmanifest` |
| Episode list | Nothing — it comes from the Buzzsprout RSS feed automatically |

## Adding a walkthrough

1. Write the guide as Markdown: `walkthroughs/<slug>.md` (see the two `example-*.md`
   files for the format — headings, choice tables, lists all supported).
2. Add an entry to `walkthroughs/games.json`:
   ```json
   { "slug": "<slug>", "title": "Game Name", "summary": "One-line teaser.", "updated": "2026-07-20" }
   ```
That's it — the walkthrough index and the home-page teaser cards read `games.json`.
Delete the two `example-*` placeholders once real guides exist.

## Structure

- `index.html` — the whole main page (inline CSS/JS)
- `shared.css` — theme tokens + shared components (colors sampled from the artwork:
  sky `#23b4ff`, deep `#3d57ee`, page `#fafafa`)
- `walkthroughs/` — `index.html` (list), `view.html?game=<slug>` (renders the Markdown),
  `games.json` (manifest), `*.md` (the guides)
- `md.js` — tiny vendored Markdown renderer (no CDN dependencies)
- `assets/` — `cover.jpg` + `header.png` downloaded from the Buzzsprout page;
  `icons/` generated by `make-icons.py` (needs Pillow)
- `manifest.webmanifest` + `sw.js` — PWA install + offline shell (the RSS feed is never
  cached)
